Nat.bertrand

theorem Nat.bertrand (n : ℕ) (hn : n ≠ 0) :
  ∃ p, Nat.Prime p ∧ n < p ∧ p ≤ 2 * n

Bertrand's postulate: for every positive natural number n there is a prime p with n < p ≤ 2n.
